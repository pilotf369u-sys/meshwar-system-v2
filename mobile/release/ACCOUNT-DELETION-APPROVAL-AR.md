# مقترح تشغيل حذف الحساب — يحتاج اعتماداً، وليس إجراءً مطبقاً

بعد استلام مخطط المالك وتعريفات الدوال الأربع، لا نحتاج تغيير دوال الدخول أو التقييم الموجودة. التطبيق وقارئات المتاجر والتسعير تبقى كما هي.

## المسؤول والوقت المقترحان

إدارة KINTO تتولى الطلبات عبر لوحة الإدارة وبريد support@shopkinto.com. المقترح تأكيد الاستلام والرد الأولي خلال 7 أيام، والمعالجة خلال 30 يوماً كهدف خدمة. لا تُنشر هذه المواعيد قبل قبول المالك والقدرة على تنفيذها؛ ليست مدة قانونية مفترضة.

## نطاق التنفيذ المطلوب

- التحقق من صاحب الحساب قبل الإجراء، دون طلب كلمة المرور أو رمز الدخول في المحادثة أو الملاحظات.
- شمول بيانات الحساب والسلة والمفضلة وقراءة الإشعارات والمحتوى الشخصي والرسائل والوسائط الخاصة به؛ جرد الصور القديمة داخل القاعدة والصور الحديثة فيStorage معاً.
- إبطال مسارات الجلسات المرتبطة فعلياً؛ لا الاكتفاء بجلسة التقييم مع تجاهلcustomer_portal_sessions.
- فحص customers.cart_items/rewards_log/reward_balances واللقطات داخلorders.details وorder_store_segments.customer_snapshot والطلبات العالمية والدفع، لا الاكتفاء بعمودcustomer_id.
- عدم حذف ملف مشترك أو سجل يخص عميلاً آخر. لا مطابقة حذف بالاسم أو الهاتف وحدهما.

## حماية العمليات والأرصدة

وجود طلب نشط أو استرداد أو دفع غير محسوم أو رصيد محفظة أو التزام قائم يحيل الطلب إلى معالجة بشرية موثقة؛ لا تغيير لحالة الطلب أو قيمة الدفع أو المخزون أو رصيد مالي عبر مسار الخصوصية. لا تعد الإحالة رفضاً دائماً للحذف: يوضح الموظف ما يلزم لمعالجة الالتزام والبيانات، ويستكمل الطلب بعده.

السجلات المالية المكتملة لا تُحذف عشوائياً ولا يُحتفظ بكل بيانات العميل بلا نهاية. قبل تنفيذ المحو لحساب ذي معاملات، يجب تحديد الحد الأدنى المحتفظ به وسبب الاحتفاظ ومدته أو معيار انتهائه، وفصل البيانات الشخصية غير اللازمة. لم يحدد المالك مدة الاحتفاظ ولم نفترضها عنه. تعليمات النسخ الاحتياطية واستعادتها تحتاج مطابقة إعدادات المزود الفعلية.

## متى نقول «اكتمل الحذف»؟

بعد إثبات تنفيذ النطاق المعتمد وإبطال الجلسات ومعالجة الوسائط وإيضاح الاستثناءات المعتمدة للعميل، لا بمجرد استلام الطلب أو إخفاء الحساب أو تعطيل الدخول. يبقى منفذ الإنتاج مقفلاً حتى تنفيذ هذه الخطوات واختبارها على حساب مصطنع مرتبط ببيانات واقعية البنية، مع بقاء حساب آخر وطلباته وأرصدته كما هي.

هذا المقترح لا يجيز تنفيذSQL أو حذف حساب إنتاجي أو دمج أو نشر. الاعتماد المطلوب الآن يخص مسؤول المعالجة وأهداف 7/30 يوماً؛ بقية الاحتفاظ المالي يحتاج قراراً منفصلاً موثقاً قبل تطبيقه.
