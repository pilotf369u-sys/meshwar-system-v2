# ورقة إجابات Data Safety — للمراجعة قبل Console

**لا تُرسل كما هي.** لم نجمع سجلات عملاء لإعدادها. الدعم مؤكد من المالك: support@shopkinto.com. لا توجد أداة إعلانات/تحليلات أصلية في تطبيق Java، لكن التطبيق يعرض موقعاً حياً ومتاجر خارجية؛ لا يصح إقرار«لا جمع بيانات».

| فئة Google المحتملة | المحتوى الفعلي | الغرض | ما يمنع تثبيت الإجابة النهائية |
|---|---|---|---|
| Personal info / Name, Email, User IDs, Address, Phone | بيانات الحساب والتسليم/الجلسة | App functionality،Account management،الحماية | تحديد المطلوب/الاختياري لكل حقل ومطابقة إعدادات الإنتاج |
| Financial info / Purchase history | طلبات وفواتير ومراجع دفع | تنفيذ الشراء والدعم | لا نخلط مرجع الدفع برقم البطاقة؛ تحديد أي مرفقات مالية فعلية |
| Messages / Other in-app messages | محادثات الدعم | خدمة العميل | جرد المرفقات، retention،من يطّلع عليها |
| Photos and videos / Photos | صور تقييم/مرفقات يختارها المستخدم | ميزة التقييم والدعم | لا إعلان«فيديوهات» لمجرد تشغيل فيديو تسويقي من الخادم |
| Files and docs | مستندات مرفوعة إذا سمحت الميزة | دعم/معاملة | تحديد الملف الفعلي؛ تنزيل فاتورة لا يعني جمع ملف من جهاز العميل |
| App activity / Other user-generated content | التعليق والخيارات وبيانات طلب المنتج | الوظائف والمراجعة | مطابقة التصنيف النهائي؛ لا نساوي كل رابط منتج بسجل تصفح المستخدم |
| Diagnostics / Device or other IDs | سجلات استضافة/IP أو أي معرف يجمع فعلياً | حماية وتشغيل | فحص إعدادات المزود والموقع،لا استنتاج غيابها من Manifest |

- «Collected»: نقل البيانات خارج الجهاز ضمن التطبيق أو الموقع الذي نتحكم به. Google تفرّق بين الويب المفتوح وWebView نتحكم بسلوكه؛ أدوات قراءة KINTO تضيف معالجة لا يجوز تجاهلها تلقائياً.
- «Shared»: نراجع كل ناقل/متجر/مزود فعلي وعقده. قد ينطبق استثناء مزود الخدمة الذي يعمل بالنيابة، أو النقل بتوجيه المستخدم وفق تعريف Google، لكن لا نعتمد الاستثناء دون تحقق. لا نجعل واتساب بديلاً عن إقرار تبادل البيانات إذا انطبق.
- التشفير أثناء النقل: التطبيق يمنع HTTP/mixed content؛ هذا دليل أصلي فقط. يلزم جرد جميع endpoint/المحتوى/الإعدادات الفعلية قبل إقرار شامل.
- طلب الحذف: الصفحة موجودة في التحضير؛ البريد مؤكد؛ **لا تضع علامة حذف مكتمل قبل تجربة إجراء حذف فعلي على حساب مصطنع**.
- Security review badge/independent audit: لا يوجد دليل تقييم معتمد، فلا يختار.
- الإعلانات والجمهور والتصنيف: استبيانات منفصلة؛ التقييمات والصور وإمكانية تصفح محتوى خارجي يجب وصفها بصدق، لا اختيار «لا محتوى مستخدم».
