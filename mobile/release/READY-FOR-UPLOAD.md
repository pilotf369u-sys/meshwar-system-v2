# KINTO — حالة حزمة النشر

**حزمة التحضير متاحة، وليست AAB معتمداً للرفع.** مرجع التطبيق هو نسخة28 ذات الافتتاحية المعتمدة من المالك؛ لم نغيّر سلوك التطبيق أو مساراته؛ عولجت ملاحظاتLint بتسمية الثابتVERTICAL بدلاً من1 وتصحيح مسافة بادئة فقط. بريد الدعم يعمل حسب تأكيد المالك.

تم تجهيز وصف المتجر، الشعار المعتمد والغلاف، جرد البيانات وورقة إقرارات، صفحات خصوصية/حذف للمراجعة، خطة اختبار وتعليمات المراجع وخطوات Console، وتدقيق الحزمة وLint وفحص أندرويد29. النتائج الفعلية تسجل في PREPARATION-RESULTS.md عند اكتمالها، لا قبل ذلك.

## الموانع الباقية قبل إعلان «جاهز للرفع»

1. **Console والتوقيع:** ملكية التطبيق/اسم الحزمة/أعلى إصدار وشهادتا App signing وUpload، ثم بناء AAB نهائي. لا نغيّر البصمة الحالية ولا ننشئ مفتاح إنتاج الآن.
2. **الخصوصية والحذف:** اعتماد مسؤول التنفيذ وحدود الاحتفاظ، تجربة حذف حساب مصطنع فعلياً مع الملفات والجلسات والنسخ الاحتياطية، ثم نشر السياسة وصفحة الحذف العامة بإذن. عمل البريد يغلق بند استقبال الدعم فقط.
3. **التقييمات:** مراجعة الأدمن موجودة؛ لم يثبت وجود قبول قواعد المحتوى قبل الرفع وأدوات إبلاغ وحظر داخل الواجهات المفحوصة. يجب إكمالها وفحصها دون تغيير البيع/الطلبات. راجع PLAY-POLICY-MATRIX.
4. **المتاجر الخارجية:** عدم ادعاء الشراكة لا يكفي وحده لإثبات حق عرض كل موقع داخل WebView. يلزم حسم التفويض/شروط الاستخدام قبل الرفع؛ لا نعطل المتاجر أو نغير طريقة حسابها ضمن التحضير.
5. **حسابات الاختبار والصور والإقرارات:** حساب مراجع مصطنع صالح، صور فعلية للواجهات النهائية دون بيانات شخصية، بيانات الجمهور/الإعلانات/IARC وData Safety مطابقة فعلياً.
6. **الحزمة النهائية ومسار Google:** فحص الحزمة الموقعة نفسها على جهاز حقيقي، اختبار Google المسبق، والاختبار المغلق إذا انطبق، ثم طلب إتاحة الإنتاج. قبول الهوية ليس قبول التطبيق.

بناء الإنتاج مقفول افتراضياً في play-verified-config.example.json؛ لا نرفع الأعلام إلا بعد وجود أدلة. لا يوجد سكربت يرفع أو يرسل للمراجعة أو ينشر تلقائياً.
