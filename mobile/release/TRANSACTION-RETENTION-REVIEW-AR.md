# مراجعة تنفيذ الاحتفاظ بالمعاملات قبل حذف ملف العميل

26 أكتوبر 2026 — تصميم للمراجعة، لا تعليمات تشغيل أو موافقة حذف.

المعتمد سابقاً: التشغيل بصفة شخصية، السوق الحالي العراق، العلامة داخل التطبيق KINTO، هدفا خدمة 7/30 يوماً، واختيار داخلي مبدئي لسبع سنوات للسجل المالي الضروري دون إتلاف تلقائي. لا نعيد طلب اعتماد هذه الخيارات. لم يُحسم في السجل بلد النشاط القانوني الحالي أو انطباق أساس المدة عليه؛ السوق المستهدف والصفة الشخصية لا يحسمان ذلك. لا تُرفع legal_applicability_verified بناءً على هذه المراجعة.

| طلب قديم بلا رابط هوية مثبت | ربط موثق مستقل أو إبقاء الحالة قيد مراجعة | لا تطابق تلقائي بالاسم أو الهاتف، ولا حذف شامل للجداول |
| بيانات غير مالية مرتبطة بالحساب | معالجة خاصة بملكيتها، مع إيصال فعلي قبل إعلان الاكتمال | ملفات مشتركة أو إثباتات طلبات لا تُحذف بسبب إمكانية العميل فتحها |

## سجل القرار اللازم

لكل عنصر محتفظ به: رابط السجل المثبت، فئة السبب، الحقول الضرورية دون نسخ قيمها إلى سجل تدقيق آخر، مرساة المدة إن ثبتت، موعد مراجعة، وبصمة المحتوى/المخطط التي تُبطل القرار عند التغير. لا يكفي زر «احتفاظ سبع سنوات» على كامل الحساب أو JSON مجهول. لا تُصاغ مدة داخلية على أنها التزام قانوني مؤكد قبل معرفة البلد المنطبق.

المنفّذ الحالي ما زال للحساب الجديد المؤهل فقط. لا نوسّع سماحه إلى معاملات حقيقية قبل إنهاء سجل القرارات ومعالجة الارتباطات وإثبات الجلسات والملفات والنسخ. مطابقة قارئ الفاتورة لا تغطي وحدها بقية 149 جدولاً.
