# اعتماد الفاتورة الإلكترونية على بيانات الحساب

فُحصت دوال first/details/customerData الحالية من js/kinto-bundle-ui-v93.js نفسها داخل VM معزول، دون استدعاء hydrateCustomer أو أي طلب شبكة. نجحت أربع حالات ببيانات مصطنعة في electronic-invoice-profile-check.test.cjs.

- بعد hydration تستمد الفاتورة المشتركة سبعة حقول من الملف الحي: الاسم والكود والهاتف والهاتف الإضافي والبلد والمحافظة والعنوان.
- customer_snapshot الخاص بقطعة المتجر وحده لا يدخل هذا الإسقاط المشترك؛ إثبات استقلال القارئ القديم V96 لا يكفي للفاتورة الإلكترونية.
- details.customer الكامل يصلح fallback عند فقد الملف، لكنه قد يعرض هوية مختلفة عما كانت تعرضه الفاتورة من الملف الحي. المثال المصطنع أثبت ذلك.
- إذا كانت القيم المحفوظة تساوي الحية، تبقى الحقول السبعة متطابقة دون تغيير الطلب أو مبلغه أو حالته.

لم تُغيّر الفاتورة أو الحقول المجمدة أو أي حساب. هذا عائق فعلي أمام فصل الملف الشخصي دون تأثير على الفواتير؛ لا يرفع نجاح فحص الإشعارات هذا العائق. يجب أن يثبت المنهي اكتمال الهوية الضرورية المستقلة لكل فاتورة قبل إزالة ملف العميل؛ لا ينسخ الهوية تلقائياً إلى كل الطلبات ولا يغيّر فاتورة مجمدة لتجاوز الحارس. لا يدعي التقرير تأهيل جميع مولّدات الفواتير أو تنفيذ الحذف الكامل.

## نطاق الإصلاح المصرّح

التعديل في مساعد بيانات العميل والتحميل فقط داخل js/kinto-bundle-ui-v93.js. لا تحديث قاعدة بيانات أو ملء تلقائي للقطات قديمة، ولا تغيير للأرقام أو الخصومات أو المخزون أو الدفع أو الحالات. يلزم وجود الحقول السبعة صراحةً كنصوص، مع اسم وكود وهاتف غير فارغة؛ قيمة الهاتف الإضافي المحفوظة الفارغة تبقى فارغة ولا تستبدل بهاتف حالي. لا تجمع اللقطة الناقصة تلقائياً مع ملف حي لتوهم الاستقلال.

نجحت8حالات لوظائف المصدر الفعلية، وفحوص حساب خصم الفاتورة وإثبات فاتورة التاجر ومسار العميل والموظف والمدير. فحص نطاق المصدر يعكس الاستبدالين المصرح بهما إلى النص السابق ثم يقارن SHA256 الأصلي؛ لا يكتفي باعتماد بصمة جديدة لكل ملف الفاتورة.

أضيف اختبار متصفح يرسم الفاتورة الفعلية قبل وبعد غياب الملف، ويثبت الاسم والعنوان المحفوظين والمبلغ والحالة وعدم طلب ملف العميل. نتيجته لا تزال تنتظر CI. لا يعني الإصلاح إغلاق حذف الحسابات القديمة ذات بيانات الفواتير الناقصة أو بقية ملفاتها ونسخها.
