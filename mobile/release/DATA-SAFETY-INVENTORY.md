# جرد أولي لأمان البيانات — ليس إقراراً مقدماً إلى Google

| البيانات | الاستخدام المرصود | ما يلزم التحقق منه قبل الإقرار |
| --- | --- | --- |
| الاسم والهاتف والبريد والعنوان | الحساب والتواصل وتسليم الطلب | الحقول المطلوبة/الاختيارية، سياسة الاحتفاظ والحذف |
| معرف العميل والجلسة | المصادقة وعزل بيانات الحساب | انتهاء/إبطال الجلسات؛ عدم تضمين الرموز في السجلات |
| الطلبات والمشتريات والفواتير ومراجع الدفع | تنفيذ الطلب والمحاسبة | الحد الأدنى الواجب الاحتفاظ به وسببه ومدته؛ لا ادعاء أن التطبيق يخزن بيانات البطاقة |
| الرسائل والصور والمرفقات | دعم العميل والتقييمات والفواتير | الحذف من قواعد البيانات والتخزين والنسخ الاحتياطية وفق سياسة معتمدة |
| اختيارات المنتج وروابطه وسعره | طلب المنتجات العالمية | مشاركة الرابط/الخيارات مع فريق التنفيذ والمتجر/الناقل عند اللزوم |
| الكوكيز وبيانات تصفح المتاجر الخارجية | جلسة تصفح منفصلة | سياسات كل متجر وطلبات شبكته؛ لا نصرّح بأن المتاجر لا تجمع بيانات |
| سجلات الشبكة والأخطاء | تشغيل الاستضافة والخدمة | إعدادات Hostinger/Supabase وأي SDK/محتوى خارجي فعلي على الويب |

الصلاحية الأصلية في Manifest هي INTERNET فقط؛ اختيار الملفات عبر منتقي النظام لا يساوي صلاحية وصول شامل للصور. لا SDK إعلانات/تحليلات أصلي مضاف في هذا المشروع، لكن ذلك لا يثبت غياب جمع بيانات عبر الويب. لا تستخدم عبارة «لا نجمع بيانات».

لا نملأ فئات مشاركة/جمع Google آلياً من هذا الجدول. يجب مطابقة التشغيل الفعلي والشركاء والإعدادات مع تعريفات Google الحالية، وتحديد الواجب/الاختياري والغرض والتشفير والحذف لكل فئة.
